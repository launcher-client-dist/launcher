How to get started

  1. Download the launcher (ClientLauncher.exe, about 66 MB, Windows 10/11 64-bit).
  2. Open it. It installs itself for your user (no admin rights, no .NET install), downloads the game client and checks every file.
  3. Create your account right inside the game client and make your character.
  4. Join the community Discord. Every Opengea player is on it: it is where you ask questions, report bugs and hear about updates.
