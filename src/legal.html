4. Privacy

No sensitive data is published. Nothing is shared or sold. Opengea keeps only the minimum needed to run the game, never uses it for advertising or profiling, and never sends it to anyone.

4.1 This website

  • No cookies, no analytics, no tracking and no ads.
  • Your language choice is saved only in your own browser (local storage).
  • To show the latest versions, your browser asks the public GitHub API for the release numbers. The site is hosted on GitHub Pages; GitHub handles these requests under its own privacy statement.

4.2 The launcher

  • The launcher only downloads public files (game, news, patch notes) from the official GitHub releases. It does not connect to the game server and sends no telemetry.

4.3 Your game account

  • Password: never stored. The server keeps only a salted one-way hash (PBKDF2-SHA256), so nobody, including the team, can read it.
  • E-mail: never stored either. The server keeps only a one-way hash of it, used only to stop the same address from creating two accounts. No e-mail is ever sent.
  • Game data: your login name, characters and progress, needed to play.
  • Technical logs: connection logs that include IP addresses, used only for security (for example, limiting login attempts and stopping abuse) and to fix problems. Passwords, tokens and e-mails are removed from these logs.
  • Backups: the server state is backed up so the game can be restored after a failure.

4.4 Sharing

Your data is not sold, rented or shared with anyone. The only other parties involved are the infrastructure providers that host the server and carry its traffic (the server host, Cloudflare and GitHub), which only process it to provide their service.

4.5 Your rights (LGPD)

Under the Brazilian General Data Protection Law (LGPD, Law nº 13.709/2018) you may ask to access, correct or delete your data, including deleting your account. Contact the team in game (a Game Master) or through the official channels.

4. Privacidade

Nenhum dado sensível é divulgado. Nada é compartilhado ou vendido. O Opengea guarda só o mínimo necessário para o jogo funcionar, nunca usa esses dados para publicidade ou perfil e nunca os envia para ninguém.

4.1 Este site

  • Sem cookies, sem analytics, sem rastreamento e sem anúncios.
  • Sua escolha de idioma fica salva apenas no seu próprio navegador (armazenamento local).
  • Para mostrar as versões mais recentes, seu navegador consulta a API pública do GitHub. O site é hospedado no GitHub Pages; o GitHub trata essas requisições conforme a sua própria declaração de privacidade.

4.2 O launcher

  • O launcher só baixa arquivos públicos (jogo, notícias, notas de atualização) das versões oficiais no GitHub. Ele não se conecta ao servidor do jogo e não envia telemetria.

4.3 Sua conta no jogo

  • Senha: nunca é guardada. O servidor guarda apenas um hash irreversível com salt (PBKDF2-SHA256), então ninguém, nem a equipe, consegue lê-la.
  • E-mail: também nunca é guardado. O servidor guarda só um hash irreversível dele, usado apenas para impedir que o mesmo endereço crie duas contas. Nenhum e-mail é enviado.
  • Dados do jogo: seu login, personagens e progresso, necessários para jogar.
  • Logs técnicos: registros de conexão que incluem endereços IP, usados só para segurança (por exemplo, limitar tentativas de login e impedir abusos) e para corrigir problemas. Senhas, tokens e e-mails são removidos desses registros.
  • Backups: o estado do servidor tem cópia de segurança para o jogo poder ser restaurado após uma falha.

4.4 Compartilhamento

Seus dados não são vendidos, alugados nem compartilhados com ninguém. Os únicos terceiros envolvidos são os provedores de infraestrutura que hospedam o servidor e transportam o tráfego (a hospedagem do servidor, a Cloudflare e o GitHub), que só os processam para prestar o próprio serviço.

4.5 Seus direitos (LGPD)

Pela Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018) você pode pedir acesso, correção ou exclusão dos seus dados, incluindo a exclusão da sua conta. Fale com a equipe no jogo (um Game Master) ou pelos canais oficiais.
